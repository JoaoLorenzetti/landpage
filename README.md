## 🎯 Sobre o Projeto

O site da Pindorama Pets foi desenvolvido para apresentar os serviços da clínica veterinária de forma profissional e acolhedora. O projeto conta com uma interface moderna, intuitiva e totalmente responsiva, adaptando-se perfeitamente a diferentes dispositivos.

### Principais objetivos:
- ✅ Apresentar os serviços da clínica
- ✅ Facilitar o contato com clientes
- ✅ Divulgar campanhas e promoções
- ✅ Mostrar a equipe de profissionais
- ✅ Exibir avaliações de clientes

## ⚡ Funcionalidades

### 🎠 Carrosséis Interativos
- **Carrossel de Campanhas (Desktop)**: Três banners rotativos apresentando vacinação, adoção e banho & tosa
- **Carrossel de Avaliações**: Sistema de paginação para exibir depoimentos de clientes

### 📱 Design Responsivo
- Layout otimizado para mobile (320px - 768px)
- Layout adaptado para tablets (768px - 1024px)
- Layout completo para desktop (1024px+)
- Breakpoints específicos para 1440px e 1920px

### 🎨 Seções Principais
1. **Hero Section**: Apresentação impactante com call-to-action
2. **Quem Somos**: Informações sobre a clínica
3. **Nossos Serviços**: Detalhamento dos serviços oferecidos
4. **Cuidados**: Destaque para o cuidado com os pets
5. **Profissionais**: Equipe de veterinários
6. **Avaliações**: Depoimentos de clientes satisfeitos
7. **Contato**: Formulário e informações de localização

### 🎯 Interatividade
- Navegação suave entre seções
- Animações nos carrosséis
- Efeitos hover em botões e links
- Validação de formulário de contato

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilização avançada com:
  - Flexbox e Grid Layout

## 🚀 Como Usar

1. **Clone o repositório**
```bash
git clone https://github.com/seu-usuario/pindorama-pets.git
```

2. **Navegue até o diretório**
```bash
cd pindorama-pets
```

3. **Abra o arquivo HTML**
- Abra `integrada.html` (ou `index.html`) em seu navegador
- Ou use um servidor local como Live Server (VS Code)

4. **Personalize**
- Edite os textos no HTML
- Modifique cores e estilos no CSS
- Ajuste funcionalidades no JavaScript

## 📱 Responsividade

O site foi desenvolvido seguindo a abordagem **Mobile First** e inclui breakpoints para:

| Dispositivo | Largura | Observações |
|-------------|---------|-------------|
| Mobile Small | 320px | iPhone SE, Galaxy Fold |
| Mobile Medium | 375px | iPhone 12/13/14 |
| Mobile Large | 425px | Smartphones grandes |
| Tablet | 768px | iPads, tablets Android |
| Laptop | 1024px | Notebooks padrão |
| Desktop | 1440px | Monitores Full HD |
| Large Desktop | 1920px+ | Monitores 4K |

### Diferenças Mobile vs Desktop

**Mobile:**
- Menu hambúrguer
- Layout em coluna única
- Carrossel de campanhas simplificado
- Imagens otimizadas

**Desktop:**
- Menu de navegação horizontal
- Layout em grid de múltiplas colunas
- Carrossel de campanhas completo com 3 banners
- Seção de cuidados adicional
- Footer expandido
